Privacy Policy

Last updated: October 11, 2026

1. About the Application

Fruxevane Private is a desktop application in development, designed to help users manage video uploads and private TikTok posts for accounts they authorize.

2. Information Processed

When TikTok integration is enabled, the application may process authorized account information, access tokens, selected video files, captions, and publishing status information.

3. Use of Information

Information is used only to provide account authorization, video upload management, and publishing functionality requested by the user.

4. Storage and Sharing

The application is designed to operate locally. Video content and necessary authorization information may be transmitted to TikTok to perform requested operations. We do not sell user information to advertisers.

5. Third-Party Services

Publishing functionality depends on TikTok and its applicable policies. This website is hosted using GitHub Pages.

6. User Control

Users can revoke application authorization through TikTok's available account settings. Locally stored application data can be removed from the user's device.

7. Policy Changes

This policy may be updated as the application develops. Material changes to data processing will be reflected here.

8. Contact

For project inquiries, visit: GitHub Issues. Please do not post private information publicly.
